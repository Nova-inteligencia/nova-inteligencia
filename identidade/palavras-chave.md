## Frases de Posicionamento

| Frase | Uso |
|---|---|
| "Empresas de bem" | Filtro de cliente e posicionamento de valor — aparece em bio, apresentação, proposta |
| "Há mais de 10 anos ajudando empresas de bem a crescerem em seus mercados" | Apresentação completa — site, proposta, LinkedIn |
| "Inteligência de marca" | Nome do serviço/metodologia de repositório no GitHub |
| "Diagnóstico antes de execução" | Diferencial no processo — usar em conteúdo educativo e proposta |
| "Marketing que funciona" | Tagline informal — quando o contexto permite |
| "Sistema de comunicação" | Alternativa a "estratégia de marketing" — mais concreto |

## Vocabulário Preferido vs. Evitado

| Em vez de... | Use... |
|---|---|
| "Pacote de serviços" | "Escopo" ou "proposta" |
| "Prestamos serviços" | "Trabalhamos como parceiros" |
| "Soluções inovadoras" | Nome específico do que é entregue |
| "Transformamos marcas" | "Construímos autoridade e visibilidade" |
| "Engajamento orgânico" | "Alcance real de quem importa" |
| "Disruptivo" | Descreva o que é diferente, com dado |
| "Estamos à disposição" | CTA específico: "Vamos conversar?" |
| "Qualidade excepcional" | Case ou dado que prove |

## Termos Técnicos de Marketing — Com Tradução

> Para usar quando falando COM clientes que não são do marketing.

| Termo técnico | Como explicar para o cliente |
|---|---|
| **CTR** | "Taxa de clique — de 100 pessoas que viram, quantas clicaram" |
| **CPL** | "Custo por lead — quanto custou cada contato interessado" |
| **ROAS** | "Retorno do anúncio — para cada R$1 investido, quanto voltou em venda" |
| **Funil de vendas** | "A jornada do cliente desde descobrir até comprar" |
| **Tráfego orgânico** | "Quem chega no seu site ou perfil sem anúncio pago" |
| **Remarketing** | "Anúncio para quem já visitou seu site ou interagiu antes" |
| **Persona** | "Perfil detalhado do seu cliente ideal — quem é, o que pensa, o que quer" |
| **Benchmark** | "Análise dos concorrentes — o que estão fazendo e como se comparam" |
| **Arquétipo** | "A personalidade da sua marca — como ela se comportaria se fosse uma pessoa" |
| **Calendário editorial** | "O plano de quais conteúdos serão publicados, quando e em qual canal" |

## Frases para Encerramento de Conteúdo (CTAs)

**Suaves (educativo / topo de funil):**
- "O que você faria diferente depois disso?"
- "Qual dessas situações você já viveu?"
- "Salva esse post se fizer sentido para o seu negócio."

**Médios (consideração):**
- "Quer ver como isso se aplica ao seu negócio? Me chama no direct."
- "Manda esse post para o dono de negócio que precisa ouvir isso."
- "Qual é a maior dificuldade de marketing no seu negócio agora? Comenta."

**Diretos (conversão):**
- "Se quiser conversar sobre como isso funciona para o seu negócio, o link está na bio."
- "Diagnóstico gratuito para os próximos [X] interessados — link na bio."
- "Agende uma conversa sem compromisso: [link]"

## Termos que Definem o Posicionamento

1. **Autoridade** — o que construímos para os clientes e para nós mesmos
2. **Visibilidade** — consequência de ter autoridade — ser visto por quem importa
3. **Consistência** — marketing que funciona precisa de sistema, não de viral
4. **Profundidade** — vamos fundo antes de executar
5. **Parceria** — não somos fornecedor, somos parceiros estratégicos
