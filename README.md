## Estrutura deste Repositório

```
nova-inteligencia/
├── README.md                     ← este arquivo
├── agent.md                      ← ponto de entrada para IA
├── contexto/
│   ├── sobre-a-empresa.md        ← história, missão, diferenciais
│   ├── publico-alvo.md           ← personas dos clientes ideais da Nova Inteligência
│   ├── concorrentes.md           ← outras agências e posicionamento competitivo
│   └── servicos.md               ← catálogo de serviços oferecidos
├── identidade/
│   ├── tom-de-voz.md             ← como a Nova Inteligência fala
│   ├── palavras-chave.md         ← vocabulário, termos e frases da marca
│   ├── design-system.md          ← paleta, tipografia, estilo visual
│   └── referencias.md            ← marcas e agências de referência
├── campanhas/
│   └── _template-campanha.md     ← briefing padrão para campanhas próprias
├── prompts/
│   ├── copy-social.md            ← prompts para redes sociais da Nova Inteligência
│   ├── ads-meta.md               ← prompts para anúncios de captação de clientes
│   └── email-marketing.md        ← prompts para nutrição e prospecção
└── historico/
    └── aprendizados.md           ← cases, resultados e aprendizados de campanha
```

---

## Como Usar

1. Abra `agent.md` e cole no Claude antes de qualquer produção
2. Consulte `contexto/` para entender o posicionamento da agência
3. Use os `prompts/` para criar conteúdo e campanhas
4. Registre aprendizados em `historico/aprendizados.md` após cada campanha
